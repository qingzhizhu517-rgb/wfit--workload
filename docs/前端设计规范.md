# 前端设计规范（WFIT · RuoYi-Vue3 + Element Plus）

> 精简版。约束对象：`front/RuoYi-Vue3/src` 全部页面与组件。
> 定位：在 Element Plus 原生风格上做「克制、统一」的视觉增强，**不引入新组件库，不改业务逻辑**。

## 0. 三条铁律

1. **颜色一律复用 `--el-*` 变量**，禁止在组件/页面里新增 hex 色值；项目级 token 统一用 `--wfit-*`。
2. **间距走 8px 栅格**，用 `--wfit-space-*`，避免 5px/7px/13px 等零碎值。
3. **兼容暗黑主题**：所有自定义样式必须能在 `html.dark` 下正常呈现（阴影、背景、边框都走变量）。

## 1. 项目级 Token（`src/assets/styles/tokens.scss`）

| 分类 | Token | 值 | 用途 |
|---|---|---|---|
| 圆角 | `--wfit-radius-sm` | 4px | 标签、按钮、输入框、小卡片 |
| | `--wfit-radius-md` | 8px | 卡片、弹窗、面板 |
| | `--wfit-radius-lg` | 12px | 登录卡片等大容器 |
| | `--wfit-radius-circle` | 9999px | 胶囊、圆形 |
| 阴影 | `--wfit-shadow-sm` | 0 1px 3px /5% | 卡片悬浮 |
| | `--wfit-shadow-md` | 0 2px 12px /8% | 卡片默认 |
| | `--wfit-shadow-lg` | 0 4px 20px /10% | 弹窗、抽屉 |
| 间距 | `--wfit-space-xs/sm/md/lg/xl/2xl` | 4/8/16/24/32/48px | 8px 栅格 |
| 字号 | `--wfit-font-xxs..2xl` | 11/12/13/14/16/20/24/28px | 层级阶梯 |
| 字重 | `--wfit-font-weight-regular/medium/semibold/bold` | 400/500/600/700 | 强调层级 |
| 行高 | `--wfit-line-height-tight/normal/relaxed` | 1.25/1.6/1.75 | 标题/正文/长文 |
| 过渡 | `--wfit-ease` | cubic-bezier(.4,0,.2,1) | 统一缓动 |
| | `--wfit-transition` / `--wfit-transition-slow` | 0.2s / 0.3s | 统一时长 |

> 暗黑模式下 `html.dark` 会覆盖 `--wfit-shadow-*` 为深色投影，避免浅色阴影在暗底上形成光晕。

## 2. 语义色（复用 Element Plus，不新增）

| 语义 | 变量 | 说明 |
|---|---|---|
| 主色 | `--el-color-primary` / `-light-3/-light-9/-dark-2` | 品牌、链接、主按钮 |
| 成功 | `--el-color-success` | 已达标、已完结、金额为正 |
| 警告 | `--el-color-warning` | 待处理、超额、需注意 |
| 危险 | `--el-color-danger` | 未达标、驳回、删除 |
| 信息 | `--el-color-info` | 中性提示、次要操作 |
| 文本 | `--el-text-color-primary/regular/secondary/placeholder` | 标题/正文/辅助/占位 四档 |
| 边框 | `--el-border-color / -light / -lighter` | 边框三档 |
| 填充 | `--el-fill-color / -light / -lighter` | 表头、斑马纹、hover 底色 |
| 背景 | `--el-bg-color`（组件白）/ `--el-bg-color-page`（页面浅灰） | 层级对比 |

## 3. 使用示例（可直接套用）

```scss
// 页面容器：浅灰底 + 24px 留白（app-container 已全局统一）
.app-container { padding: var(--wfit-space-lg); }

// 页头：标题 + 副标题 + 操作区（全局已提供 .page-header）
.page-header {
  display: flex; align-items: flex-start; justify-content: space-between;
  gap: var(--wfit-space-md); margin-bottom: var(--wfit-space-lg);
  .page-title { font-size: var(--wfit-font-xl); font-weight: var(--wfit-font-weight-semibold); color: var(--el-text-color-primary); }
  .page-desc  { margin-top: var(--wfit-space-xs); font-size: var(--wfit-font-sm); color: var(--el-text-color-secondary); }
}

// 卡片：白底 + 8px 圆角 + 悬浮阴影（Element Plus 原生，无需重复）
.el-card { border-radius: var(--wfit-radius-md); border: 1px solid var(--el-border-color-lighter); }

// 状态标签：语义色 + 4px 圆角
.el-tag { border-radius: var(--wfit-radius-sm); font-weight: var(--wfit-font-weight-medium); }

// 表格表头：浅灰底 + 加粗（table.scss 已全局统一）
// 关键数值：主色/警告色语义化
.total-num  { font-weight: 700; color: var(--el-color-primary); }
.excess-num { font-weight: 600; color: var(--el-color-warning); }

// 空状态 / 辅助文案
.el-empty .el-empty__description p { color: var(--el-text-color-secondary); }
```

## 4. 组件视觉基线（已全局统一）

| 组件 | 规范 |
|---|---|
| 按钮 | 圆角 `--wfit-radius-sm`，过渡 `--wfit-transition`，主按钮默认 500 字重 |
| 卡片 | 8px 圆角 + 极浅边框 + 悬浮 `--wfit-shadow-sm` |
| 表格 | 表头 600 字重浅灰底、斑马纹 `--el-fill-color-lighter`、单元格 8px 上下内边距 |
| 对话框 | 12px 圆角 + `--wfit-shadow-lg` + 页头分隔线 |
| 抽屉 | 页头分隔线 + 24px 留白 |
| 标签 | 4px 圆角 + 500 字重 |
| 分页 | 右对齐 + 移动端隐藏跳转/每页条数 |
| 空状态 | `--wfit-space-xl` 上下留白 + 辅助色文案 |
| 滚动条 | 8px 细滚动条，`--el-border-color`，Firefox 用 `scrollbar-width: thin` |

## 5. 响应式断点

| 断点 | 处理 |
|---|---|
| ≥1920 / 1440 / 1024 | 桌面，侧边栏 200px，内容自适应 |
| ≤991px | 移动布局，侧边栏抽屉化（`translate3d`），主区 `margin-left: 0` |
| ≤768px | 分页隐藏「跳转/每页条数」；表单 `el-form--inline` 自动换行 |
| 表格 | 始终可横向滚动（`el-table` 自带），固定列用 `fixed` |

## 6. 约定清单（后续页面遵守）

- 业务页 scoped 样式里，颜色/间距/圆角/字号**只允许** `var(--el-*)` 与 `var(--wfit-*)`。
- 状态、金额、趋势用统一语义色（见 §2），禁止同一含义多种颜色。
- 新页面统一用 `.app-container` 包裹 + `.page-header` 作标题区。
- 过渡统一 `var(--wfit-transition)`，禁止 600ms 之类硬编码时长。
- 改样式只动 `<style>`，禁止改 template 结构 / props / 接口 / 权限。
