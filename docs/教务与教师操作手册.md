# 潍理工教学工作量管理系统操作手册

> 适用对象：教务人员、教师
> 适用范围：教学任务导入、工作量申报与核算、汇总审核、酬金查询及报表导出
> 文档版本：2026-09-11

## 1. 使用前必读

本系统用于完成教师教学任务维护、教学工作量核算、教师自主申报、学期汇总审核和绩效酬金查询。不同角色看到的菜单和按钮不同：

- **教务人员**负责基础数据维护、教学任务导入、工作量核算、汇总审核和报表导出。
- **教师**负责查看本人教学任务与工作量、申报允许自主填报的项目、核对并提交学期汇总、查看本人酬金。
- 页面没有显示某个按钮时，通常表示当前账号没有相应权限，或当前数据状态不允许操作。

### 1.1 推荐浏览器

建议使用最新版 Chrome、Edge 等现代浏览器，并保持浏览器缩放比例为 100%。导入或导出 Excel 时，请勿在文件下载完成前关闭页面。

### 1.2 登录与首次改密

1. 打开系统登录页。
2. 输入账号或工号、密码和验证码。
3. 点击“登录”。
4. 首次登录或管理员重置密码后，系统会强制进入个人中心修改密码；修改完成前不能访问其他业务页面。
5. 新密码长度应为 6～20 个字符。修改成功后重新进入首页。

> 测试环境可能提供初始账号，正式环境请使用管理员分配的个人账号，不要多人共用账号。

## 2. 首页与通用操作

### 2.1 教务工作台

教务人员登录后可在工作台快速查看：

- 待审核汇总数量；
- 教学任务数量；
- 参与核算的教师数量；
- 绩效酬金总额；
- 待办事项和汇总趋势；
- 教学任务导入、审核汇总、工作量明细和报表导出等快捷入口。

工作台数据用于概览，具体数据以对应业务页面为准。

### 2.2 教师工作台

教师登录后可查看本人：

- 课程数量；
- 已核算工作量；
- 超额工作量；
- 预计绩效；
- 学期汇总概览；
- 近期工作量明细。

教师可从快捷入口进入自主申报、学期汇总、工作量明细和酬金记录页面。

### 2.3 列表页通用操作

大多数列表页面都提供以下操作：

- **搜索**：输入教师、学期、类别或名称等条件后查询。
- **重置**：清空搜索条件并恢复默认列表。
- **新增/修改**：打开表单录入或调整数据。
- **删除**：删除单条或批量选中的数据；删除前会要求二次确认。
- **导出**：按当前查询条件导出 Excel。
- **分页**：切换页码或调整每页显示数量。

新增、修改、删除、导入等写操作会弹出确认框。点击“取消”不会提交请求；请求处理中请勿重复点击。

## 3. 教务端页面说明

### 3.1 教师档案

用于维护参与工作量核算的教师基础信息。

**主要功能**

- 按教师、职称、人员性质和特殊状态筛选；
- 新增、修改、删除教师档案；
- Excel 导入和导出；
- 查看教师档案详情。

**关键字段**

- 教师账号/工号；
- 职称；
- 人员性质；
- 额定工作量；
- 特殊状态及其他核算相关信息。

**操作建议**

1. 先确认教师系统账号已经存在。
2. 新增档案时选择教师并填写职称等必填项。
3. 导入时仅选择一个 `.xls` 或 `.xlsx` 文件。
4. 如需覆盖已有档案，根据页面提示选择“更新已有数据”。
5. 导入完成后查看成功和失败数量，并处理失败行。

### 3.2 教学任务

教学任务是 G1～G6 工作量计算的主要源数据，可手工录入，也可从 Excel 批量导入。

**查询条件**

- 教师；
- 学年学期；
- 课程名称；
- 授课层次；
- 专业大类。

**主要功能**

- 新增和修改教学任务；
- 单条删除和批量删除；
- 下载导入模板；
- Excel 导入；
- 按筛选条件导出 Excel。

**导入模板主要字段**

学年学期、教师工号、教师姓名、课程名称、课程代码、工作量类别、授课层次、专业大类、课程性质、课程级别、课程角色、教学评价、选课人数、计划学时/天数/周数、课程系数、班级、重复次序。

**重复次序说明**

- 第 1 次讲授：重复系数通常为 1.0；
- 第 2 次讲授：通常为 0.9；
- 第 3 次及以后：通常为 0.8；
- G3 按制度使用两档重复系数；
- 重复次序留空时，系统按教师、学期、课程名称和授课层次自动续算；
- 显式填写重复次序时，以填写值为准。

**手工新增/修改流程**

1. 点击“新增”或目标行的“修改”。
2. 选择教师和学期，填写课程、层次、人数、学时、班级等信息。
3. 点击“确定”。
4. 核对二次确认提示；确认后系统才会保存。
5. 保存成功后返回列表检查数据。

**Excel 导入流程**

1. 点击“下载模板”，不要随意改变模板列顺序和表头。
2. 按模板填写数据，教师工号应与系统账号一致。
3. 点击“Excel 导入”，选择一个 `.xls` 或 `.xlsx` 文件。
4. 点击“开始导入”，在确认框中核对后确认。
5. 查看导入结果中的总数、成功数和失败数。
6. 部分行失败时，成功行仍可能已经入库；请先刷新并核对列表，再修正失败行重新导入，避免重复数据。

**导出说明**

导出的首两列为“教师工号”和“教师姓名”，不会导出系统内部教师 ID。导出范围以当前搜索条件为准。

> 删除教学任务前，应确认其是否已经产生工作量明细。存在关联明细时系统会拒绝删除；确需删除时，应先按业务要求处理相关明细。删除后需重新核算受影响数据。

### 3.3 学期岗位减免

用于维护或导入教务已认定的教师本学期岗位减免工作量，是同步 G11 管理服务工作量的来源。

**主要功能**

- 按教师和学期查询；
- 批量导入“岗位减免工作量（本学期）”；
- 查看可选职务说明、数据来源和导入批次；
- 在汇总草稿阶段同步 G11。

系统直接采用教务给出的学期减免值，不根据职务名称、学年标准或任职日期再次计算。修改来源值后需重新同步 G11 并核算；待审记录应先退回草稿，已完结记录永久不可修改。

### 3.4 工作量明细

用于查看和维护教师每一项工作量记录，是核算结果追溯的核心页面。

**主要功能**

- 按教师、学期、工作量类别和状态筛选；
- 查看项目名称、核定工作量、计算公式和计算因子；
- 新增、修改和删除允许维护的明细；
- 单条重算；
- 按教师和学期进行明细重算；
- 导出明细。

**G 类明细页面**

G1～G6、G11 子页面用于查看或维护对应计算因子，例如计划学时、人数、课程系数、重复系数、岗位折算信息等。一般应优先从教学任务导入或岗位任职生成，避免主表与子表信息不一致。

**明细状态**

| 状态 | 含义 | 操作建议 |
|---|---|---|
| 草稿 | 尚未确认，可继续维护 | 核对因子后重算 |
| 已核对 | 已确认，通常进入冻结 | 如需调整，先按流程退回 |
| 有异议 | 教师或教务发现问题 | 核查源数据并处理 |
| 已驳回 | 不参与汇总 | 修改或重新申报后再处理 |

### 3.5 学期汇总

用于完成教师工作量的集中核算、提交和教务审核，也是报表导出的主要入口。

**主要功能**

- 按教师和学期查询；
- 单教师一键核算；
- 核算所选教师；
- 全学期核算；
- 同步本学期岗位减免到 G11；
- 批量提交；
- 查看汇总预览；
- 审核通过或驳回；
- 查看、追加线下补差说明（不改变原完结结果）；
- 导出汇总、表一、附件 1 和附件 2。

**汇总状态**

| 状态 | 含义 | 可执行操作 |
|---|---|---|
| 填报中 | 数据仍可补充和核算 | 申报、重算、提交 |
| 待教务审核 | 已提交，等待教务审核 | 审核通过或驳回 |
| 已完结 | 审核结束并锁定 | 查看、导出；仅管理员可解锁 |

**批量核算说明**

- “核算所选”只处理勾选的教师；
- “全学期核算”处理当前学期全部有明细的教师；
- 系统按教师分别处理，单个教师失败不会阻止其他教师完成；
- 核算完成后应查看成功数、失败数和失败原因。

### 3.6 酬金记录与其他酬金

**酬金记录**用于查看教师课时绩效酬金和其他酬金汇总，可按条件查询、维护、重算和导出。

**其他酬金**用于维护制度规定的其他项目，包括重修辅导、实习指导、论文重修、代阅卷、讲座、运动会/体测和夜间值班等。录入时应选择正确的费用类型并填写人数、次数或金额依据。

> 绩效为 0 不一定是系统错误。人员性质非专任、总工作量未超过额定值、尚未核算或数据已触及封顶规则，都可能影响结果。可结合附件 2 的备注判断。

### 3.7 核算配置

工作量类别、计算规则和职称酬金标准页面用于维护核算参数。修改后会影响后续核算结果，仅限授权人员操作。

修改配置后，应通知相关人员并重新核算受影响的教师和学期。不要仅凭经验随意调整规则参数。

## 4. 教师端页面说明

### 4.1 我的工作量/自主申报

教师只能查看和申报本人数据。当前自主申报主要用于 G8、G9 和允许申报的 G11 项目。

**申报流程**

1. 进入“我的工作量”或“自主申报”。
2. 点击“新增申报”。
3. 选择学期和工作量类别。
4. 填写项目名称、核定学时和说明。
5. 申报 G11 时按页面要求选择岗位。
6. 保存后在列表查看申报结果。
7. 草稿记录可按页面权限修改或撤回；进入审核或冻结状态后不能自行修改。

> 自主申报应填写真实、可核验的信息。G1～G6 通常来自教务导入的教学任务，不应重复申报。

### 4.2 本人工作量明细

教师可查看本人每一条工作量的类别、项目、核定学时、状态、计算公式和因子说明。

发现问题时，应记录课程、学期、类别和具体差异，联系教务核查教学任务或计算因子。汇总进入待审或完结后，相关数据可能已经冻结。

### 4.3 本人学期汇总

教师可查看本人 G7、G8、G9、G10、G11、总工作量、超额工作量和预计绩效。

**主要操作**

- 填报中：检查明细并提交汇总；
- 待教务审核：查看数据，并在页面提供入口时确认工作量；
- 已完结：查看最终结果和导出个人报表；
- 导出本人表一或附件 1。

提交前必须先核对课程是否齐全、重复次序是否正确、自主申报是否完整、各项核定学时是否合理。提交后若需修改，应联系教务驳回。

### 4.4 本人酬金记录

教师可查看本人课时绩效、其他酬金和合计金额。页面金额为系统当前核算结果，最终发放以学校正式审核和财务流程为准。

## 5. 完整业务操作流程

下面流程适用于一个学期从准备数据到最终导出的完整操作。

### 阶段一：基础资料准备（教务）

1. 检查教师账号和教师档案。
2. 补充职称、人员性质、额定工作量等核算信息。
3. 维护班主任、系主任、专业负责人、督导等岗位任职。
4. 确认工作量类别、计算规则和酬金标准已经配置正确。

### 阶段二：导入教学任务（教务）

1. 进入“教学任务”。
2. 下载最新导入模板。
3. 按模板填写课程、教师工号、类别、人数、学时、班级和重复次序。
4. 导入 Excel 并确认。
5. 查看导入结果，处理失败行。
6. 使用教师、学期和课程条件抽查导入数据。

导入成功后，系统按数据生成教学任务、工作量主记录及相应 G1～G6 明细。导入采用逐行处理，部分失败不会自动回滚已成功行。

### 阶段三：补充自主申报（教师）

1. 教师进入“我的工作量/自主申报”。
2. 申报 G8、G9 或页面允许的 G11 项目。
3. 检查申报记录是否处于草稿或正确状态。
4. 如发现教学任务缺失，联系教务处理，不重复申报 G1～G6。

### 阶段四：生成 G11 与核算（教务）

1. 在“学期汇总”选择目标学期。
2. 根据岗位任职信息执行“生成 G11”。
3. 对少量教师使用单教师或“核算所选”。
4. 全学期集中处理时使用“全学期核算”。
5. 查看核算结果中的成功数和失败原因。
6. 到工作量明细和汇总页面抽查公式、因子、封顶提示和金额。

核算顺序为：工作量明细 → 学期汇总 → 酬金记录。源数据修改后必须重新执行相关核算。

### 阶段五：教师核对与提交

1. 教师查看本人工作量明细。
2. 核对课程、班级、类别、工作量和自主申报项目。
3. 进入学期汇总检查总量和预计绩效。
4. 数据无误后提交；如有问题，提交前联系教务修正。
5. 教务也可按业务安排批量提交符合条件的汇总。

### 阶段六：教务审核

1. 教务在“学期汇总”筛选“待教务审核”。
2. 查看教师汇总和明细。
3. 数据正确时点击“审核通过”。
4. 数据有误时填写原因并“驳回”，记录回到填报中。
5. 审核通过后记录进入“已完结”并锁定。

当前审批为两级流程：填报中 → 待教务审核 → 已完结，不再包含院领导签字环节。

### 阶段七：报表与结果导出

1. 在“学期汇总”选择学期和需要的教师范围。
2. 根据用途选择普通汇总、表一、附件 1 或附件 2。
3. 附件 1 用于追溯个人工作量明细、班级、系数和计算说明。
4. 附件 2 用于查看全学期绩效酬金统计、是否触顶和备注。
5. 教学任务页面的导出用于核对原始课程任务，不等同于最终工作量报表。
6. 打开导出文件核对学期、教师范围、行数和金额。

## 6. 计算结果阅读说明

### 6.1 汇总关系

- G7 = G1～G6 合计；
- G10 = G7 + G8 + G9；
- 总工作量 = G10 + G11；
- G11 按制度存在学期封顶；
- 已驳回明细不参与汇总。

### 6.2 绩效酬金

系统按照总工作量、额定工作量、职称费率、人员性质及封顶规则计算课时绩效。页面中的“超额工作量”和“计酬超额工作量”可能不同：前者反映实际超额，后者应用计酬封顶规则。

### 6.3 常见系数提示

- G1 理论课会涉及重复系数、课程性质、质量系数和合堂系数；
- G2 实践课会涉及专业类别系数等；
- G3 实习实训按天数和指导类别计算；
- G4 课程设计按学分和实际人数计算，超阈值会提示核查；
- G5 毕业论文超申报阈值时会提示报批，但不一定截断人数；
- G6 集中实习超过规定人数的部分不计工作量；
- G11 根据岗位标准、任职日期和学期长度折算。

详细原因优先查看工作量明细中的公式、因子说明或附件 1 的“系数说明”。

## 7. 常见问题

### 7.1 找不到某个菜单或按钮

可能原因：账号角色没有权限、数据状态不允许操作，或管理员尚未完成角色授权。请提供账号角色、页面名称和缺少的按钮给管理员核查。

### 7.2 导入提示部分失败

导入按行处理，成功行可能已经保存。先查看成功数和失败原因，刷新列表并核对已导入数据，再仅修复失败行，避免整份文件重复导入。

### 7.3 教师工号无法匹配

确认模板中的工号与系统登录账号完全一致，避免前后空格、中文全角字符或误填教师姓名。无法确认时先在教师档案中查询。

### 7.4 修改了教学任务但汇总未变化

教学任务是源数据，汇总不会因为页面修改自动完成全部重算。修改后需要重新核算相应工作量明细、学期汇总和酬金。

### 7.5 无法修改或删除数据

数据可能已进入待审或已完结状态，或者已经被工作量明细引用。待审数据应先由教务驳回；已完结数据只能由管理员按权限解锁；有关联数据时应先处理关联明细。

### 7.6 核算失败如何处理

查看失败原因，并依次检查：

1. 教师档案、职称和人员性质是否完整；
2. 教学任务的学期、类别、人数和学时是否有效；
3. 对应 G 类计算明细是否存在；
4. 岗位任职和 G11 明细是否完整；
5. 工作量规则和酬金标准是否启用。

修正源数据后，仅重新核算受影响的教师和学期。

### 7.7 绩效酬金显示为 0

可能原因包括：

- 总工作量未超过额定值；
- 人员性质按制度不计发课时绩效；
- 尚未执行完整核算；
- 职称费率或教师档案不完整；
- 相关明细已驳回或未纳入汇总。

请同时查看附件 2 的备注和计酬超额工作量。

## 8. 数据操作注意事项

- 所有写操作确认前请再次核对教师、学期和数据范围。
- 不要重复点击新增、保存、删除或导入按钮；系统虽有防重复机制，仍应等待当前操作结束。
- 批量删除、批量提交、全学期核算等操作影响范围较大，执行前应先设置正确的筛选条件。
- 不要修改 Excel 模板的表头和列顺序。
- 导出文件可能包含教师业务信息，应按学校数据安全要求保存和传递。
- 审核通过后数据将锁定；审核前应完成抽查和异常处理。
- 修改教学任务、岗位任职、工作量明细或核算配置后，应重新执行受影响范围的核算。
- 页面数据与正式制度不一致时，先暂停操作并联系系统管理员或业务负责人确认，不要自行通过修改规则绕过。
