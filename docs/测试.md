## 自动化测试脚本

### API测试（需要先关闭验证码）

```bash
#!/bin/bash
# test_api.sh

BASE="http://localhost:8084"

# 1. 登录获取token
echo "=== 登录测试 ==="
RESP=$(curl -s -X POST "$BASE/login" \
  -H "Content-Type: application/json" \
  -d '{"username":"admin","password":"admin123"}')
TOKEN=$(echo $RESP | grep -o '"token":"[^"]*"' | cut -d'"' -f4)
echo "Token: ${TOKEN:0:20}..."

if [ -z "$TOKEN" ]; then
  echo "登录失败: $RESP"
  exit 1
fi

# 2. 测试获取用户信息
echo -e "\n=== 用户信息 ==="
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/system/user/info" | head -c 200

# 3. 测试教师列表
echo -e "\n\n=== 教师列表 ==="
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/system/teacherProfile/list" | head -c 200

# 4. 测试工作量汇总
echo -e "\n\n=== 工作量汇总 ==="
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/system/workloadSummary/list" | head -c 200

# 5. 测试计算接口
echo -e "\n\n=== 计算预览 ==="
curl -s -H "Authorization: Bearer $TOKEN" "$BASE/system/calc/preview?semester=2025-2026-2" | head -c 200

echo -e "\n\n=== 测试完成 ==="
```

## 常见问题排查

### 1. 登录失败
- 检查Redis是否运行
- 检查用户状态是否正常（status='0'）
- 检查密码是否正确

### 2. 数据为空
- 执行测试数据SQL
- 检查dept_id是否匹配

### 3. 计算结果错误
- 检查规则参数表 biz_workload_rule
- 检查费率表 biz_pay_rate
- 查看后端日志

### 4. 导出失败
- 检查uploadPath目录权限
- 检查POI依赖是否完整
