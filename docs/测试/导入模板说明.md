# 导入模板说明

## 1. 教学任务导入 Excel

**接口**：`POST /system/teachingTask/importExcel`
**权限**：`system:teachingTask:import`（admin、jiaowu）
**模板下载**：`POST /system/teachingTask/importTemplate`

### 字段定义

| # | 列名（表头） | 字段名 | 类型 | 必填 | 说明 |
|---|-------------|--------|------|------|------|
| 1 | 学年学期 | semester | 文本 | ✅ | 格式 `YYYY-YYYY-N`，如 `2025-2026-2` |
| 2 | 教师工号 | userCode | 文本 | ✅ | 对应 `sys_user.user_name` |
| 3 | 教师姓名 | userName | 文本 | ✅ | 用于校验，不作为匹配依据 |
| 4 | 课程名称 | courseName | 文本 | ✅ | |
| 5 | 课程代码 | courseCode | 文本 | ✅ | |
| 6 | 工作量类别 | workloadType | 文本 | ✅ | 对应 G1-G11 类型码 |
| 7 | 授课层次 | educationLevel | 文本 | ✅ | `本科` 或 `专科` |
| 8 | 专业大类 | majorCategory | 文本 | ✅ | `理工类`/`文史类`/`艺术类`/`其他` |
| 9 | 课程性质 | courseNature | 文本 | ✅ | `必修` 或 `选修` |
| 10 | 课程级别 | courseLevel | 文本 | 否 | `省级一流`/`校级优质`/`其他` |
| 11 | 课程角色 | courseRole | 文本 | 否 | `主持人`/`前3参与人`/`独立` |
| 12 | 教学评价 | teachingEval | 文本 | 否 | 教学评价结果 |
| 13 | 选课人数 | studentCount | 数字 | ✅ | 用于 G4/G5/G6 人数截断 |
| 14 | 计划学时/天数/周数 | baseValue | 数字 | ✅ | G1: 理论学时; G2: 实践学时; G3: 天数; G6: 周数 |
| 15 | 课程系数 | courseCoefficient | 数字 | 否 | 预留字段 |

## 2. 教师档案导入 Excel

**接口**：`POST /system/teacherProfile/importData`
**权限**：`system:teacherProfile:import`（admin、jiaowu）
**模板下载**：`GET /system/teacherProfile/importTemplate`

### 字段定义

| # | 列名（表头） | 字段名 | 类型 | 必填 | 说明 |
|---|-------------|--------|------|------|------|
| 1 | 教师工号 | userCode | 文本 | ✅ | 对应 `sys_user.user_name` |
| 2 | 教师姓名 | nickName | 文本 | ✅ | |
| 3 | 院部名称 | deptName | 文本 | ✅ | 对应 `sys_dept.dept_name` |
| 4 | 职称 | title | 文本 | ✅ | `教授`/`副教授`/`讲师`/`助教` |
| 5 | 人员性质 | teacherNature | 文本 | ✅ | `专任`/`外聘`/`校企`/`银龄`/`青州外聘` |
| 6 | 手机号 | phonenumber | 文本 | 否 | |
| 7 | 邮箱 | email | 文本 | 否 | |

## 3. 文件校验规则（ImportFileValidator）

| 规则 | 说明 |
|------|------|
| 文件非空 | 上传文件不能为空 |
| 扩展名白名单 | 仅允许 `.xls` 和 `.xlsx` |
| 文件大小限制 | 默认 10MB（可通过 `wfit.import.max-size` 配置） |
