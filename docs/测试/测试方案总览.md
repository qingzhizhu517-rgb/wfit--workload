# WFIT 工作量管理系统 — 端到端测试方案总览

## 1. 测试目标

验证从登录到报表导出的完整业务流程，覆盖核算引擎（G1-G11）、审批流状态机、权限隔离、异常场景，确保系统功能正确可用。

## 2. 测试环境

| 项目 | 值 |
|------|-----|
| 后端 | `http://localhost:8084` (Spring Boot) |
| 前端 | `http://localhost:3000` (Vite dev server) |
| 数据库 | MySQL `172.19.80.1:3306/wflg_workload` |
| Redis | `localhost:6379` |
| 测试学期 | `2025-2026-2`（春季，与现有数据 `2025-2026-1` 隔离） |

## 5. 核算公式速查

| 类型 | 公式 | 测试用例覆盖 |
|------|------|-------------|
| G1 | J1×C1×K1×Q1×Q2×Q3×N | 4.2~4.5 |
| G2 | J2×K×C2×Q1×Q2×Q3 | 4.6 |
| G3 | T×D×K×Q1×Q2×Q3 | 4.7 |
| G4 | J4×min(R4,20)×0.4 | 测试数据未覆盖，需手动补充 |
| G5 | R5×K5 | 4.8 |
| G6 | W×min(R6,20)×0.4 | 4.9 |
| G11 | 按岗位标准×任职天数/学期天数 | 4.10, 4.11 |
| 酬金 | (min(总工作量,540)-180)×职称费率 | 7.2 |

## 6. 执行顺序

```
执行 test_data.sql
    ↓
P1 登录 → P2 基础数据 → P3 导入 → P4 核算 → P5 申报 → P6 审批 → P7 酬金 → P8 导出
                                                                                      ↓
                                                                              PX 异常场景（穿插各阶段）
```
