#### 1. CalcStrategyFactory 缓存逻辑提取
**问题**: 类职责过多，违反 SRP 原则  
**当前文件**: `rear/workload-system/**/calc/strategy/CalcStrategyFactory.java`  
**重构方案**:
```java
// 新建 StrategyCache.java
@Component
public class StrategyCache {
    private final Map<String, WorkloadCalcStrategy> cache = new ConcurrentHashMap<>();
    private static final WorkloadCalcStrategy NULL_PLACEHOLDER = new NullStrategy();
    
    public WorkloadCalcStrategy get(String typeCode, Supplier<WorkloadCalcStrategy> loader) {
        WorkloadCalcStrategy cached = cache.get(typeCode);
        if (cached != null) {
            return cached == NULL_PLACEHOLDER ? null : cached;
        }
        
        WorkloadCalcStrategy strategy = loader.get();
        cache.put(typeCode, strategy == null ? NULL_PLACEHOLDER : strategy);
        return strategy;
    }
    
    public void evict(String typeCode) {
        cache.remove(typeCode);
    }
    
    public void clear() {
        cache.clear();
    }
}
```

**修改 CalcStrategyFactory**:
```java
@Component
public class CalcStrategyFactory {
    @Autowired
    private Map<String, WorkloadCalcStrategy> strategyMap;
    
    @Autowired
    private BizWorkloadCategoryDictMapper categoryDictMapper;
    
    @Autowired
    private StrategyCache strategyCache;
    
    public WorkloadCalcStrategy get(String typeCode) {
        return strategyCache.get(typeCode, () -> loadStrategyFromDatabase(typeCode));
    }
    
    private WorkloadCalcStrategy loadStrategyFromDatabase(String typeCode) {
        BizWorkloadCategoryDict dict = categoryDictMapper.selectByTypeCode(typeCode);
        if (dict == null || !StringUtils.hasText(dict.getCalcStrategy())) {
            return null;
        }
        return strategyMap.get(dict.getCalcStrategy());
    }
}
```

**测试要求**: 单元测试

#### 3. 添加策略解析日志
**问题**: 缺少日志记录，调试困难  
**当前文件**: `rear/workload-system/**/calc/strategy/CalcStrategyFactory.java`  
**重构方案**:
```java
private static final Logger log = LoggerFactory.getLogger(CalcStrategyFactory.class);

private WorkloadCalcStrategy loadStrategyFromDatabase(String typeCode) {
    log.debug("解析类别 {} 的计算策略", typeCode);
    
    BizWorkloadCategoryDict dict = categoryDictMapper.selectByTypeCode(typeCode);
    if (dict == null) {
        log.warn("未找到类别配置: {}", typeCode);
        return null;
    }
    
    String strategyBeanName = dict.getCalcStrategy();
    if (!StringUtils.hasText(strategyBeanName)) {
        log.debug("类别 {} 未配置计算策略", typeCode);
        return null;
    }
    
    WorkloadCalcStrategy strategy = strategyMap.get(strategyBeanName);
    if (strategy == null) {
        log.error("未找到策略Bean: {} (类别: {})", strategyBeanName, typeCode);
    }
    
    return strategy;
}
```

**预计工作量**: 30分钟  
**风险**: 低  
**测试要求**: 日志验证

#### 4. login.vue 方法拆分
**问题**: handleLogin 方法过长，包含多个逻辑分支  
**当前文件**: `front/RuoYi-Vue3/src/views/login.vue`  
**重构方案**:
```javascript
function handleLogin() {
  proxy.$refs.loginRef.validate(valid => {
    if (!valid) return
    
    loading.value = true
    saveLoginCredentials()
    
    userStore.login(loginForm.value)
      .then(handleLoginSuccess)
      .catch(handleLoginFailure)
  })
}

function saveLoginCredentials() {
  if (loginForm.value.rememberMe) {
    Cookies.set("username", loginForm.value.username, { expires: 30 })
    Cookies.set("password", encrypt(loginForm.value.password), { expires: 30 })
    Cookies.set("rememberMe", loginForm.value.rememberMe, { expires: 30 })
  } else {
    Cookies.remove("username")
    Cookies.remove("password")
    Cookies.remove("rememberMe")
  }
}

function handleLoginSuccess() {
  const query = route.query
  const otherQueryParams = Object.keys(query).reduce((acc, cur) => {
    if (cur !== "redirect") {
      acc[cur] = query[cur]
    }
    return acc
  }, {})
  router.push({ path: redirect.value || "/", query: otherQueryParams })
}

function handleLoginFailure() {
  loading.value = false
  if (captchaEnabled.value) {
    getCode()
  }
}
```
