## M5：审批流与报表导出（1 周）

### Task 5.1：审批状态机（2 天）

**目标**：实现三级审批流程

**状态流转**：
```
0: 填报中 (教师/教务员可编辑)
  ↓ 教务员提交
1: 教务助理待审 (教务助理可审核)
  ↓ 教务助理通过/驳回
2: 院领导待签 (院领导可签字)
  ↓ 院领导签字
3: 已完结 (锁定，不可修改)
  ↓
-1: 驳回 (回到填报中，可修改后重新提交)
```

**后端**：
1. `AuditController.java` — 审批操作端点
   - POST `/system/audit/submit` — 提交审核
   - POST `/system/audit/approve` — 教务助理通过
   - POST `/system/audit/reject` — 驳回
   - POST `/system/audit/sign` — 院领导签字
2. `AuditService.java` — 审批逻辑
   - 状态校验（不可越级）
   - 签名记录（账号 + 时间）
   - 锁定机制（已完结不可修改）

**前端**：
1. `workloadSummary/index.vue` 添加审批按钮
2. 审批历史弹窗
3. 签名组件

**产出**：
- `AuditController.java`
- `AuditService.java`
- 审批 UI 组件

## 技术决策

| 决策点 | 选择 | 理由 |
|--------|------|------|
| Excel 库 | POI 5.5.1（已有） | 已在依赖中，无需引入 EasyExcel |
| 导入方式 | 同步导入 + 异步回调 | 数据量不大（百行级），同步即可 |
| 审批签名 | 账号 + 时间戳 | 简单实现，后续可升级为电子签章 |
| 报表模板 | POI 模板填充 | 保持与学校格式一致 |

| 风险 | 概率 | 影响 | 应对 |
